🔐 Cấu hình xác thực

Thêm vào .env: <PREFIX>_USERNAME + <PREFIX>_PASSWORD

Thêm vào .env: <PREFIX>_USERNAME + <PREFIX>_PASSWORD. Client sẽ gửi header Authorization: Basic base64(user:pass).

Thêm vào .env: <PREFIX>_TOKEN=eyJhbG…. Client sẽ gửi header Authorization: Bearer <token>.

Thêm vào .env: <PREFIX>_KEY=sk-…. Chọn Query param nếu app source yêu cầu ?api_key=xxx.

Thêm vào .env: <PREFIX>_USERNAME=readonly_user + <PREFIX>_PASSWORD=xxx. Dùng account read-only. Backend chỉ chấp nhận SELECT/WITH, block UPDATE/DELETE/DROP.

Mở connection + ping SELECT 1, không chạy query.
